## 1. 공통 좌표계

| 항목 | 값 |
|---|---|
| 캔버스 | 512 × 1024 px, 투명 PNG(RGBA), 배경 없음 |
| 발바닥 기준선 | y = 1000 (맨발 기준. 신발 밑창은 y=1000 아래로 최대 8px까지 허용) |
| 가로 중심 | x = 256 (남자), x = 259 (여자 몸 중심) |
| 원본 → 캔버스 배율 | 원본 1254px 그림 × 0.8564 (남녀 같은 배율 → 원본의 남녀 키 차이 그대로 유지) |
| 남자 키 | 960px (y 40 → 1000) |
| 여자 키 | 944px (y 56 → 1000) |
| 1px | = 리그 1단위. 게임에서는 키 약 150px로 축소되어 보임 |

모든 파츠·의상 PNG는 **512×1024 전체 캔버스에, 기본 자세의 원래 자리에 그대로** 그립니다(잘라서 옮기지 않음). 잘라내기와 위치 계산은 빌드 스크립트가 자동으로 합니다.

### 분리 기준 (원본에서 자른 선)

## 3. 움직일 때 드러나는 부분 보완 (직접 그려야 함)

자동으로 지우거나 늘려서 만들면 원본 그림이 손상되기 때문에, 아래는 **그려서** 넣어야 합니다. 지금 시범 동작은 이 부분이 드러나지 않도록 움직임 폭을 작게 제한해 두었습니다.

| 부분 | 무엇을 | 크기 |
|---|---|---|
| 몸통 옆구리 | 팔에 가려진 겨드랑이~옆구리 피부와 외곽선을 팔 뒤까지 이어서 | 팔 안쪽 경계에서 바깥으로 20px |
| 팔 윗부분 | 어깨 관절을 둥근 모양으로 완성(몸통과 겹치는 부분) | 어깨점 위·안쪽으로 15~20px |
| 허벅지 | 속옷 안쪽 허벅지를 위로 연장(다리를 들 때·짧은 하의 입을 때 보임) | 골반선에서 위로 80px |
| 목 | 턱에 가려진 목을 위로 연장(고개 움직임) | 30px |
| 대머리 머리 | 머리카락 없는 두피·이마·귀(헤어 교체용) | head.png와 같은 자리 |
| 기본 헤어 | 지금 머리 그림의 머리카락만: 앞머리(얼굴 위) / 뒷머리(얼굴 뒤) 두 장 | head.png와 같은 자리 |

## 4. 방향별 기본 바디 (아직 없음 — 제작 필요)

방향: `front`(정면, 완료), `back`(뒷면), `left`(화면 왼쪽을 봄), `right`(화면 오른쪽을 봄).
각 방향 모두 같은 캔버스·같은 발 기준선(y=1000)·같은 키·같은 머리 크기로 그립니다.

권장 파츠(무릎·팔꿈치가 접혀야 걷기가 자연스러움 — 하이브리드 리그):

| 파츠 이름 | 내용 | 회전축(관절) |
|---|---|---|
| head | 대머리 머리(얼굴 포함) | neck |
| torso | 목·몸통·골반·속옷 | 골반 중심 |
| upperArmL / upperArmR | 어깨~팔꿈치 | shoulderL / shoulderR |
| lowerArmL / lowerArmR | 팔꿈치~손 | elbowL / elbowR |
| upperLegL / upperLegR | 골반~무릎 | hipL / hipR |
| lowerLegL / lowerLegR | 무릎~발끝 | kneeL / kneeR |

- 관절이 만나는 곳은 양쪽 파츠 모두 **둥글게 10~15px 겹치게** 그립니다(굽혀도 틈이 안 생김).
- 측면(left/right)은 몸 뒤쪽 팔·다리가 앞쪽 팔·다리보다 약간 어둡게(그림자 10%).
- 측면은 이 구조로 디딤발이 바닥에 정확히 고정되는 걷기를 코드로 만듭니다(보폭 34px).
- 정면·뒷면은 깊이 방향 이동이라 실제 보폭을 표현할 수 없어서 "제자리 디딤 + 접지 순간" 동작으로 만듭니다(3/4 탑다운 게임 공통 방식).
- 고품질을 위해 추가로 그리면 좋은 키포즈(선택): 정면·뒷면 `lowerLegL_lift`, `lowerLegR_lift`(무릎을 굽혀 발을 든 모습).
- 각 방향 폴더에 `joints.json`(관절 좌표)을 넣습니다. 형식은 `art/avatar/base/male_base/front/joints.json` 참고. 관절 좌표를 모르면 그림에 빨간 점으로 찍어 보내주시면 제가 넣습니다.

### 방향별 겹침 순서 (아래 → 위)
- 정면: 뒷머리 → 다리L·R → 몸통 → 하의 → 상의 → 팔L·R(소매) → 아우터 → 머리 → 앞머리 → 액세서리
- 뒷면: 앞머리 → 머리 → 팔L·R → 다리L·R → 몸통 → 하의 → 상의 → 아우터 → 뒷머리(머리카락이 얼굴을 덮음)
- 왼쪽 보기: 먼 팔(R) → 먼 다리(R) → 몸통 → 하의·상의 → 가까운 다리(L) → 머리·헤어 → 가까운 팔(L)
- 오른쪽 보기: 먼 팔(L) → 먼 다리(L) → 몸통 → 하의·상의 → 가까운 다리(R) → 머리·헤어 → 가까운 팔(R)

## 5. 헤어·의상 레이어 규격

**모든 의상은 붙을 신체 파츠와 같은 이름으로, 기본 자세의 그 자리에** 그립니다. 그 파츠가 움직이면 의상도 정확히 같이 움직입니다.

| 칸(slot) | 그릴 파일(방향마다) | 비고 |
|---|---|---|
| hair | `head.png`(앞머리, 얼굴 위), `head_back.png`(뒷머리, 몸 뒤) | 긴 머리는 뒷머리가 어깨 아래로 내려와도 됨 |
| top (상의) | `torso.png`, `upperArmL.png`, `upperArmR.png`(소매), 긴팔이면 `lowerArmL.png`, `lowerArmR.png` | 반팔은 upperArm만 |
| bottom (하의) | `torso.png`(허리·골반 부분), `upperLegL.png`, `upperLegR.png`, 긴바지면 `lowerLegL.png`, `lowerLegR.png` | 바지 허리는 몸통에, 바짓가랑이는 다리에 |
| shoes (신발) | `lowerLegL.png`, `lowerLegR.png`(발 부분만) | 맨발 위에 덮음 |
| outer (아우터) | top과 같음 + 필요하면 `torso_back.png`(몸 뒤로 보이는 자락) | 상의 위에 그려짐 |
| accessory | `head.png`(모자·안경·귀걸이) 또는 `torso.png`(목걸이) | |

- 지금 정면 기본 바디는 팔·다리가 통째로 1장씩(armL, legL…)이라, 정면 의상은 `armL.png`, `legL.png` 이름으로도 받습니다.
- 남녀 체형이 달라 의상은 성별 폴더를 따로 둡니다. 같은 그림이 맞으면 `unisex`.
- 의상은 몸보다 1~2px 크게(외곽선 포함) 그려서 피부가 비치지 않게 합니다.

## 6. 파일 이름 규칙 / 폴더 구조

```
art/avatar/
  source/                                   공식 원본(수정 금지)
  base/{male_base|female_base}/{front|back|left|right}/
      head.png  torso.png  armL.png ... (또는 upperArmL.png ...)  joints.json
  items/{hair|top|bottom|shoes|outer|accessory}/{itemId}/
      item.json                             {"name":"흰 티셔츠","price":3000}
      {male|female|unisex}/{front|back|left|right}/{파츠이름}.png  (뒤에 그릴 레이어는 _back)
```

- itemId: 영문 소문자·숫자·밑줄만(예: `tee_white`, `jeans_blue`, `sneakers_white`, `hair_short_black`)
- 기존 상점 아이템 ID와 연결: `tee`, `shirt`, `hoodie`, `tank`(상의) / `jeans`, `slacks`, `shorts`(하의) / `sneakers`, `loafers`, `runners`(신발) / `hair1`, `hair2`(헤어) / `tbcard`, `gcard`(아우터). 같은 ID로 폴더를 만들면 기존 구매 기록과 바로 이어집니다.

## 7. 게임에 넣는 방법

1. 위 폴더 구조대로 PNG를 넣습니다(512×1024, 원래 자리 그대로).
2. 빌드: `python3 src/build_site.py` → `gen_manifest.py`가 자동으로 잘라서 `assets/avatar/`에 넣고 `manifest.json`을 다시 만듭니다. 캔버스 크기가 틀리거나 빈 파일이면 `manifest.json`의 `problems`에 표시됩니다.
3. 확인: `avatar-lab.html`(아바타 실험실)에서 착용·걷기를 확인합니다.
4. 이미지를 Claude에게 보내주시면 위 과정을 대신 합니다.

## 8. 먼저 만들 테스트 목록 (남녀 각각)

| 구분 | 아이템 | 필요한 장수(4방향, 10파츠 리그 기준) |
|---|---|---|
| 기본 바디 | 뒷면·왼쪽·오른쪽 3방향 × 10파츠 | 30장 |
| 대머리 머리 | 4방향 | 4장 |
| 기본 헤어 | 앞/뒤 × 4방향 | 8장 |
| 추가 헤어 2종 | 앞/뒤 × 4방향 × 2 | 16장 |
| 티셔츠 2종 | 몸통+소매2 × 4방향 × 2 | 24장 |
| 바지 2종 | 허리+다리4 × 4방향 × 2 | 40장 |
| 신발 2종 | 양발 × 4방향 × 2 | 16장 |

정면의 팔·다리를 10파츠(팔꿈치·무릎 분리)로 다시 나눈 버전도 있으면 좋습니다. 정면도 무릎이 접히는 걷기가 가능해집니다.
